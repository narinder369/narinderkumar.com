# narinderkumar.com

> Premium Personal Brand & All-in-One Digital Business Platform

Built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS 4**, and **Supabase (PostgreSQL + RLS)**.

## Overview
NarinderKumar.com combines five business verticals under a unified, high-contrast monochrome design system:
1. **Creative & Digital Services**: AI UGC video creation, video production, WordPress development, Next.js engineering, digital marketing, and UI/UX design.
2. **Digital Products Store**: Practical eBooks, templates, prompt packs, and creator resources.
3. **Software & Online Tools**: Free and premium browser utilities (AI Prompt Generator, Hook Crafter, Niche Idea Engine).
4. **Blog & Knowledge Hub**: Technical tutorials and case studies.
5. **Custom Admin Dashboard**: Executive telemetry, product CRUD, order audits, and client inquiry management.

## Tech Stack
- **Framework**: Next.js 16 with Turbopack & React 19
- **Styling**: Tailwind CSS 4 with custom monochrome design tokens
- **Database & Storage**: Supabase (PostgreSQL + Row-Level Security)
- **Payments**: Dual integration (Razorpay for INR/UPI & Stripe for Global)
- **State Management**: Zustand with persistent storage
- **Hosting & CI/CD**: Vercel

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live platform.
